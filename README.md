# 반짝! 단위 정원

태희·세희를 위한 도량형과 백분율 이야기 학습 앱.

## 사용

- [학습 앱](https://01chungee10snu.github.io/fairy-math-garden/)
- 길이(cm/m), 무게(g/kg), 거리(m/km), 퍼센트 혼합 놀이
- 새싹: 전체·절반, 반짝: 다양한 백분율
- 총 48개 검토된 문항, 각 코스/난이도 6개 중 한 회 5개
- 개념 그림을 움직이기 → 이야기 문제 → 정답과 풀이 → 보상
- 태희·세희별 독립 기록, 브라우저 로컬 저장, 보호자 메뉴의 JSON 내보내기/병합 가져오기
- 기기의 한국어 음성을 사용할 수 있으면 문제 읽어주기 지원

## 실행 및 확인

외부 라이브러리 설치나 API 키 없이 정적 파일로 실행합니다.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
# http://127.0.0.1:4173
node --check app.js
node scripts/check-content.mjs
```

GitHub Pages는 `main` 브랜치의 루트(`/`)를 게시합니다. 변경 후 커밋/푸시하면 갱신됩니다. `.nojekyll`을 포함합니다.

## 학습 및 보상

`questions.js`가 문항 데이터입니다. `percent`는 항상 **남은 비율**, `total`은 처음 전체, `result`는 남은 실제 양입니다. 0%와 100%도 포함합니다. 그림은 개념을 돕는 비율 표현이며 실제 자처럼 화면에서 실측하는 도구가 아닙니다.

문항별 생애 최대 별 10개. 첫 정답 10개, 첫 오답+해설 2개, 나중에 정답을 찾으면 차액 8개. 중복 클릭·복습으로 점수가 중복 지급되지 않습니다. 누적 별 30/80/150/240개에 새싹/꽃/나비/왕관을 받습니다. 시간 제한·감점·아이 간 순위는 없습니다.

## 데이터

서버, 회원가입, 분석 추적, 외부 데이터베이스가 없습니다. 기록은 이 기기의 해당 브라우저 저장소(`fairy-math-garden-v1`)에만 있습니다. 자동 기기 간 동기화는 없습니다. 저장소 삭제 전 보호자 메뉴에서 내보내세요. 가져오기는 기존 기록과 높은 점수를 병합합니다. 점수는 교육용 기록으로 서버 인증되지 않습니다.

다음 단계에서 가족용 공유 저장이 필요하면 Supabase 등의 인증·행 수준 접근 제어를 설계해 연결할 수 있습니다. 관리자 비밀키를 프런트엔드에 넣지 않습니다.

## 디자인·자산

- 자체 제작 요정 일러스트: `assets/fairy-companions.webp`, AI 생성
- 주아체: 우아한형제들, SIL Open Font License 1.1 (`assets/OFL-Jua.txt`)
- 폰트 원본: https://github.com/google/fonts/tree/main/ofl/jua
- 캐치티니핑의 밝은 요정 분위기를 참고했으며 등장 캐릭터와 로고는 자체 구성
- WebMCP 지원 브라우저에서는 진도 읽기/개념 화면 열기를 점진적으로 제공합니다. 일반 브라우저에는 영향이 없습니다.

## 유지보수

- `index.html`: 문서와 메타데이터
- `style.css`: 반응형 화면과 접근성
- `app.js`: 학습 흐름, 저장, 보상, 읽어주기
- `questions.js`: 검토된 문항 원본
- `scripts/check-content.mjs`: 문항별 산술·변환·선택지 검사

새 문항 작성 시 전체의 기준, 사용량과 잔여량, 소수 단위 변환을 함께 검수합니다. 실제 아이의 이해 수준과 표현 난이도는 보호자 관찰로 조정합니다.
